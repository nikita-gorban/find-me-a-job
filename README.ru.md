# Job Finder Kit — поиск работы с ИИ-помощником

*[Read in English](README.md)*

Представьте эту папку как **блокнот на вашем компьютере**: одна таблица со списком вакансий, остальные страницы — черновики сопроводительных писем и резюме. Рядом — **ИИ-помощник внутри Cursor** (чат-приложение для работы с файлами). Он ищет вакансии и пишет черновики; **вы** читаете, правите и сами нажимаете «откликнуться». Помощник не должен **придумывать опыт** — только реальные факты.

Программистом быть не нужно. Нужны Cursor, интернет и время один раз заполнить свои данные.

**Кит работает локально-first** — см. [Локальная работа (важно)](#локальная-работа-важно) ниже.

**Не на Cursor?** `AGENTS.md` — общий формат, который читают несколько ИИ-инструментов (Cursor, Claude Code, Windsurf и другие). Любой из них подойдёт — просто замените сочетание клавиш из [CURSOR.md](CURSOR.md) на аналог вашего инструмента.

## Получить кит

**Клонировать с GitHub:**

```bash
git clone https://github.com/nikita-gorban/find-me-a-job.git
cd find-me-a-job
```

**Или** на GitHub: **Code → Download ZIP** → распаковать → открыть папку в Cursor.

> **Не дружите с git?** ZIP вполне достаточно. Кит скачивается один раз; ежедневный поиск работы **не требует** GitHub, коммитов или пушей.

Ваши реальные папки заявок в `applications/` — **в `.gitignore`**: черновики и PDF остаются только на вашем компьютере и **не** предназначены для публичного репозитория.

## Локальная работа (важно)

Проект **рассчитан на локальную работу на вашем компьютере**, а не как облачное приложение или репозиторий, который вы обновляете во время откликов.

| | Один раз (настройка) | Каждый день (поиск работы) |
|---|---|---|
| **Что вы делаете** | Скачали кит → открыли в Cursor → заполнили `AGENTS.md` и cv-base | Общаетесь с помощником, правите `tracker.md` и файлы в `applications/` |
| **Git / GitHub** | Опционально: `git clone` или ZIP | **Не требуется** — коммитить и пушить не нужно |
| **Где живут данные** | Та же папка на диске | Та же папка; опционально iCloud / Dropbox / **приватный** git-бэкап |

**Почему:** сопроводительные письма, адаптированные резюме и история откликов — личные данные. Публичный репозиторий — это **шаблон**; ваш поиск работы по умолчанию остаётся локальным (`applications/` в `.gitignore`).

**Не** пушьте свои материалы для откликов в [find-me-a-job](https://github.com/nikita-gorban/find-me-a-job) — форкайте, только если хотите доработать сам кит, в **отдельной** приватной копии.

## С чего начать

**Откройте [ONBOARDING.md](ONBOARDING.md)** — пошаговая первая настройка (~15–30 минут, можно с перерывами).

**Вся схема целиком:** [flow-diagram.svg](flow-diagram.svg) (картинка) · [FLOW.md](FLOW.md) (диаграммы в Cursor)

Коротко: установите Cursor → откройте **эту папку** → заполните резюме и правила → напишите помощнику первое сообщение.

Подробнее про чат и клавиши: [CURSOR.md](CURSOR.md).

## Как это работает (просто)

1. **Помощник** находит вакансии и записывает их в [tracker.md](tracker.md) (нумерованная таблица).
2. **Вы** говорите: «мне нравятся #3 и #7».
3. **Помощник** создаёт черновики в `applications/<#>-<slug>/`: заметки по вакансии, сопроводительное письмо, иногда — адаптированное резюме.
4. **Вы** правите текст, пока он не зазвучит как вы, и говорите «ок» или «сделай короче».
5. Если нужен **PDF-резюме** (не для hh.ru) — одна команда в терминале (см. ONBOARDING).
6. **Вы** сами отправляете отклик на сайте работодателя.

Помощник **не** откликается за вас и **не** обещает оффер. Он экономит время на рутинных черновиках.

## Два типа площадок

| Где откликаетесь | Что готовим в папке | Ваше резюме на момент отклика |
|-----------------|------------------------------|------------------------------|
| **hh.ru** | `<#>-cover.md` + заметки | Резюме уже на hh (из вашего `cv-base-ru.md`, см. [cv-base-ru.example.md](cv-base-ru.example.md)) |
| **Другие** (email, Lever, Greenhouse…) | `<#>-cover.md` + `<#>-cv.md` + PDF при необходимости | Файлы прикладываете сами |

## Статусы в трекере

| Слово | Значит |
|------|--------|
| `new` | Нашли, ещё не начинали |
| `prep` | Готовим cv/cover или ждём ваших правок |
| `ready` | PDF резюме готов (или на hh: cover готов) |
| `applied` | Уже откликнулись |
| `declined` | Отказ или тишина — строка остаётся для истории |
| `closed` | Вакансия закрыта/снята — строка остаётся для истории |
| `skip` | Сознательно не идём — строка остаётся для истории |

## Полезно знать

- **Локально-first** — работайте в папке на своём компьютере; git опционален после скачивания (см. [Локальная работа](#локальная-работа-важно)).
- Помощник может ошибаться — **всегда читайте**, прежде чем что-то отправлять.
- Начинайте первый чат с **`@AGENTS.md`**, чтобы он прочитал ваши правила.
- Сопроводительные письма: **короткие**, 3–5 предложений, на **языке текста вакансии**.
- Python и PDF — **опциональны**, в основном если откликаетесь не через hh и нужен файл PDF. См. ONBOARDING.

**Поделиться китом:** короткий текст для мессенджера — в [SHARE.md](SHARE.md) (русский + английский).

Застряли на каком-то шаге? Спросите в чате: «Я на шаге X в ONBOARDING и …»
