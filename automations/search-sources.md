# Job search sources — local reference

> **For the agent:** `@automations/search-sources.md` — extended platform and direct-careers list.  
> Base scan algorithm — [`vacancy-scan.md`](vacancy-scan.md). Remote / language / role filters — `AGENTS.md` only.

---

## How to use

1. Start with aggregators (Tier A–B in `vacancy-scan.md`).
2. Every 2–3 days — **one** block from sections below (MVEC, Notion list, or 3–5 direct careers).
3. For each vacancy: active link, explicit full remote, fit via `cv-base-en.md`, dedupe with `tracker.md`.
4. Localization vendors and gamedev studios — **spot-check careers**, do not bulk-add without an open role.

## Maintenance

- Update "last verified" date when you spot-check a block.
- Remove or flag sources that consistently return expired or non-remote postings.
- Personal tracker row references belong in your local `vacancy.md`, not in this shared template.
