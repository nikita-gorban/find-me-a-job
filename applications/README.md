# applications/

One folder per vacancy: `applications/<#>-<slug>/` (e.g. `5-acme-pm/`)

| File | Purpose |
|------|---------|
| `<#>-vacancy.md` | Job notes for the agent (URL, fit, gaps) |
| `<#>-cover.md` | Cover letter (3–5 sentences) |
| `<#>-cv.md` | Tailored resume — **non-hh** platforms only |
| `*.pdf` | Generated by script; not committed to git |

**Slug:** lowercase Latin letters and hyphens, no spaces. Use forward slashes in paths and chat: `applications/5-acme-pm` (Windows too).

**Git:** your application folders are in `.gitignore` — they stay local only.

## Folders starting with `_`

Directories like [`_example-do-not-track/`](_example-do-not-track/) are **structure examples** without a tracker number. Do not add them to [tracker.md](../tracker.md). For a real application, the helper creates e.g. `applications/5-acme-pm/5-vacancy.md`.
